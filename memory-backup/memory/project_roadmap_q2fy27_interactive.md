Built 2026-07-06. A customer-facing **interactive** HTML roadmap generated from `Scott's Copy of Q2FY27 - Abnormal Roadmap [PMM Revision] [Approved].pptx` (29 slides). Distinct from the evergreen [[project_roadmap_v4_design]] and the [[anthropic-skills:roadmap-scott]] site — this is a per-deck "navigate, don't scroll" experience marketing asked for.

**Output:** `C:\Claude\projects\roadmap\abnormal-roadmap-q2fy27.html` (single self-contained file, ~7 MB, images base64-embedded and deduped via a JS `IMAGES` map).

**Nav model (Scott's spec):** Splash → (click) Safe Harbor → (click) **Hub** (mirrors slide 4 platform diagram; 5 category tiles + analytics: 18 items / 5 areas / 3 new products / 5 free / 8 paid + Aug→Nov ’26 availability timeline) → click a **category** → feature cards w/ badge+one-liner+date → click a card → **rebuilt feature slide** (challenge / solution / benefits / availability + embedded product screenshots w/ thumbnail switcher). Keeps all product-slide content 100% (marketing requirement) but re-typeset on-brand. Breadcrumb + back + prev/next + keyboard (←/→/Esc/H).

**Categories — RESTRUCTURED 2026-07-22 to 4 (was 5):** Email Security (7), Identity Security (4), AI Security (1), **Insider Threat (6)**. Per-category accent: Email=Electric Green, Identity=Magenta, AI=Sun Orange, Insider=Red 01 `#EE234B`. **Human Risk Management is NO LONGER a top-level area** — it's folded UNDER Insider Threat as a drill-in "blade": the Insider detail view shows 2 cards (Infiltration Prevention [the product] + a "Human Risk Management" blade → `data-go="cat-hrm"`); clicking the blade opens the `cat-hrm` sub-screen listing HRM's 5 capabilities (recolored cyan→red). In `NAV.cats`, `hrm` has `"parent":"insider"` and its 5 feats have `cat:"hrm"`; `updateChrome` uses a new `crumbChain()` helper so breadcrumbs nest (Platform / Insider Threat / Human Risk Management / <feature>). The **"8 paid upgrades" hero stat was removed** (badge stays per-card); hub stats now = 18 items / **4 areas** / 3 new / 5 free. (Insider tile still reads "6 features" = 1+5 capabilities though the view shows 2 blades — flagged to Scott as a possible tweak.)

**Available Now section (added 2026-07-22):** a secondary section showing already-shipped/live capabilities (narrative: "here's what you already own → here's what's coming"). 11 items sourced from [[project_roadmap_v4_design]]'s "Recently released" set (`roadmap-v4.html`). Entry = a green CTA banner on the hub (`.avail-cta` → `data-go="screen-available"`) → `#screen-available` grid of simple LIVE cards → `av-<id>` detail screens (single-column, description only, **no screenshots** per Scott). The AVAIL data + `av-` detail screens are generated by an injected `buildAvailable()` IIFE (appends sections to body, registers them in `screens`); breadcrumb/back/showBack extended for `screen-available` + `av-`.

**Rebuild pipeline** (all in `C:\Claude\projects\roadmap\q2fy27-extract\`): `extracted-slides.json` (from slides skill's html-extract-pptx.py) → `compress.py` (resize≤1500px + base64 → `assets_b64.json`) → `build_html.py` (holds the full DATA model + renders screens; reads `styles.css` + `app.js`) → writes the HTML. To regenerate after edits: `python build_html.py`. **⚠️ GOTCHA (2026-07-22):** the 4-area / HRM-as-blade / Available-Now changes were made as **surgical hand-edits directly to the HTML**, NOT reflected back into `build_html.py` / the DATA model. Re-running `python build_html.py` will **OVERWRITE and wipe** all 2026-07-22 changes. Either keep editing the HTML directly, or port these changes into the pipeline before regenerating. A backup of the pre-2026-07-22 state is at `abnormal-roadmap-q2fy27.html.bak`.

Brand = Abnormal Corporate (Electric Green `#C7E913` = the "yellow" Scott means, on black/gray). Preview via `universe` launch config: http://localhost:3333/projects/roadmap/abnormal-roadmap-q2fy27.html (note: preview_screenshot **times out** on this page — heavy embedded-image DOM; verify with inspect/eval only, never screenshot).

**Refinements shipped (2026-07-06, same day):** splash now has the deck's hero **voxel cube** (`ppt/media/image3.png` from slideLayout1) floating on the right; **Inter is embedded as base64 woff2** (weights 400–800 in `fonts/`, no Google Fonts CDN — fully offline/self-contained, fixes corporate-network font fallback) and `text-rendering:optimizeLegibility` was removed (Chrome kerning bug = the "lettering off" complaint); green /\ AI mark in the footer of every screen; product screenshots are **click-to-zoom lightbox** (arrows + counter for multi-image); feature slides rebalanced text-heavier; **hub analytics stats are clickable filters** → a `screen-filter` results view (New Products / Free / Paid / all / by-launch-month), grid scrolls internally when >8. **IMPORTANT build gotcha:** read `styles.css`/`app.js` with `encoding="utf-8"` in build_html.py or non-ASCII glyphs (·, ⤢, ›) mojibake on Windows.

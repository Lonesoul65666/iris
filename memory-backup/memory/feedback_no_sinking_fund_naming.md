Scott (2026-06-11): "I don't like the name sinking fund or 'sinking'" — but he explicitly WANTS the feature area: saving goals for taxes, annual/irregular bills, remodels, trips, "other random shit that is due every year."

**Why:** "Sinking" reads negative/jargony — fails the couples-first plain-language bar. Same rule family as keeping "watermark"/"reserves" (his words, keep those).

**How to apply:** Use "Stashes" (already partially shipped in BudgetView) or similarly plain naming everywhere user-visible; purge "sinking fund" from UI copy. Internal type names can migrate opportunistically. The funded-balance tracking gap (audit 2026-06-11: reserve/stash balances are never actually accumulated) is the natural future feature for this area — when built, build it under the Stashes name.

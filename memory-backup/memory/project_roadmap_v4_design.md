Keep the Abnormal **Electric Green (#C7E913) palette, the real wordmark logo (full-strength white), and the name correct** — but go **creative/expressive everywhere else** (he explicitly relaxed the strict brand rules: rounded corners, glassmorphism, gradient-mesh motion, glow, 3D tilt, gradient/shimmer headline all welcome). **How to apply:** Don't enforce the full `abnormal-core:brand` rulebook on this deliverable (that's why it diverges from sharp-corners/no-motion). Keep green + logo + name correct; be bold with everything else.

**Current architecture (Scott-tuned 2026-06-22 v2 — LANDING + master-detail):** Two views via a `render()` router on `state.view` (`home` | `pillar`). **HOME (default landing)** = hero + **4 big clickable product boxes** (`Email` · `AI Tools` · `Identity` · `Human Risk`, each with a one-sentence `desc`) + a **"Recently released"** section (the `now`-bucket features as mini-cards) + a **"Where we're going"** section (`ea/q1/q2` features). Clicking a box → `enterPillar`; clicking a mini-card → `enterPillarFeature` (opens that feature). On home the controls/tabs/appView are hidden. **PILLAR view** = the **master–detail layout** (hero hidden; tab bar shows `← Overview` + the 4 pillars; clicking Overview or the topbar wordmark → `goHome`). Platform/Recent/Appendix items fold INTO a pillar via `PILLAR_OVERRIDE` (most → Email; integrations/posture/identity case-studies → Identity). Left = a sticky scannable **list** grouped by plain status headers **Available now / Coming soon / On the roadmap / Reference & proof** (`statusGroupOf`); the big "On the roadmap" + "Reference" groups start **collapsed** so it's not overwhelming. Right = **detail pane** (dark slide if any + challenge/solution/benefits/meta, reusing the `drawer-*` content classes). Clicking a list row swaps the detail without rebuilding the list (collapse state preserved). **NO horizontal scroll anywhere.** Per-pillar **search** (filters the current pillar's list). The old board/drawer/`bcard`/lane code and the `All`/status-filter-chip UI were removed; `renderApp`/`renderDetail`/`selectFeature` are the engine. ⚠️ EDITING GOTCHA that bit me: HTML/CSS edits shift line numbers, so sed-splices using pre-edit line numbers corrupt the file — re-grep boundaries immediately before any sed slice, or just use text-based Edit.

**Drawer = the real deck slide.** Clicking a card opens the wide drawer (~52vw) showing the **actual deck slide** up top, then the text (subtitle/challenge/solution/benefits/meta) + prev/next. Mapping lives in the `SLIDES` object in-file (v4 feature `id` → image) with `SLIDE_BASE`. Slide-less features fall back to text (no broken image).
